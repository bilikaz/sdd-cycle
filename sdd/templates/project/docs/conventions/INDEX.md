# Conventions

Binding engineering rules, one topic per file. Add project-specific topics here or point the workspace
map at the project's existing conventions.

| Topic | Covers |
|---|---|
| [Docker](docker.md) | Fixed environment layout, local runtime identity, isolated resources and host-wide shared services. |
| [Service ports](service-ports.md) | Port bands, service numbers and publication boundaries. |

These topics apply where the project uses Docker; they do not require a container stack for every project.
